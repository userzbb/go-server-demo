# Omega Server 通信协议文档

## 1. 传输层协议
- 传输方式：TCP
- 默认端口：8888（可配置）
- 粘包处理：4 字节大端长度前缀 + 消息体

## 2. 消息包结构
[4字节总长度] + [4字节消息ID] + [变长消息体]
- 总长度：uint32，大端序
- 消息ID：uint32，大端序
- 消息体：二进制数据（当前采用 JSON）

## 3. 消息ID分配表
| 范围 | 用途 | 示例 |
|------|------|------|
| 1000-1999 | 登录/认证 | 1001: 登录请求 |
| 2000-2999 | 房间管理 | 2001: 创建房间 |
| 3000-3999 | 游戏逻辑 | 3001: 移动同步 |
| 4000-4999 | 战斗系统 | 4001: 攻击请求 |
| 9000-9999 | 系统消息 | 9001: 心跳检测 |

## 4. 消息定义

### 4.1 登录请求 (MsgID=1001)
{"username":"player1","password":"123456"}

### 4.2 登录响应 (MsgID=1002)
{"code":0,"message":"登录成功","token":"xxx"}
code: 0=成功, 1=用户名密码错误, 2=格式错误

### 4.3 创建房间请求 (MsgID=2001)
{"roomName":"我的房间","maxPlayers":10}

### 4.4 创建房间响应 (MsgID=2002)
{"code":0,"roomId":"room_001","message":"创建成功"}

### 4.5 加入房间请求 (MsgID=2003)
{"roomId":"room_001"}

### 4.6 加入房间响应 (MsgID=2004)
{"code":0,"roomId":"room_001","players":["player1"],"message":"加入成功"}

### 4.7 心跳检测 (MsgID=9001)
{"timestamp":1234567890}

## 5. 错误码定义
| Code | 说明 |
|------|------|
| 0 | 成功 |
| 1 | 用户名或密码错误 |
| 2 | 请求格式错误 |
| 3 | 房间不存在 |
| 4 | 房间已满 |
| 5 | 玩家已在房间中 |
| 6 | Token 无效或过期 |

## 6. 协议版本管理
当前版本：v1.0
协议变更需更新本文档并通知所有客户端
